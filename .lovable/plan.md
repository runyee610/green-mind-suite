## 2. "类型"改为多选

- 下拉选项固定为两项：`绿色工厂`、`绿色供应链管理`。
- 支持多选（去掉原 Select 组件，改用带 Checkbox 的 Popover 多选控件；沿用项目已有的 `Popover + Checkbox` 组合，与其他多选场景一致）。
- 数据结构：`greenType` 由字符串改为 `string[]`；表格该列以逗号连接显示（多个类型渲染为多个 Badge）。
- 顶部"类型"筛选（原 `energyFilter`）逻辑同步更新：判断数组是否包含所选项。
- 现有 9 条 mock 数据的 `greenType` 从字符串迁移为数组（"绿色工厂、绿色供应链" → `["绿色工厂","绿色供应链管理"]`；"绿色供应链" → `["绿色供应链管理"]`）。

## 3. 移除"企业类型（能耗）"

- 新增弹窗删除该字段（`energyTag` Select 及必填校验）。
- 表单 state `AddFormState` 去掉 `energyTag`；`emptyForm`、`openEdit`、`handleAddSubmit` 相应调整。
- 表格列以及筛选栏原本没有直接展示 `energyTag`（旧代码用它给"类型" Badge 上色），改为按 `greenType` 数组决定颜色即可。
- `IncubateRecord` 中的 `energyTag` 字段本身保留在数据里（避免大范围影响其他页面），但不再暴露在表单和 UI。若无其他引用则一并删除；已确认此文件外无其它页面引用该字段，可直接删除类型定义与 mock 中的 `energyTag`。
