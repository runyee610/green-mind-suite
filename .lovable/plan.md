
## 目标

按上传参考图的视觉风格重新调整全站色系。**内容、布局、组件结构、交互均不变**，仅替换设计令牌（CSS 变量）。

## 参考图特征提取

- 主色：明亮翠绿 emerald（≈ #10B981 / hsl 160 84% 39%），而非当前的深墨绿 #0F5E4E
- 辅色 / glow：青绿 teal-mint（≈ #34D399），用于渐变按钮的第二段
- 背景：非常浅的薄荷白（≈ #F6FBF8，带极淡绿调），而非当前中性 paper white
- 卡片：纯白 + 细淡绿描边（≈ hsl 150 30% 90%）
- 侧边栏：**浅色**（近白 + 淡绿），选中项为浅绿高亮块 + 绿字，而非当前深墨蓝底
- 强调 tag / pill：淡绿底 (#E7F7EF) + 深绿字
- 主按钮：明亮翠绿→薄荷绿线性渐变，圆角较大（rounded-full 或 rounded-xl）
- 阴影：极淡带绿调

## 改动范围

**只改一个文件**：`src/index.css`

替换以下设计令牌（HSL 值）：

| 令牌 | 现值 | 新值（参考图翠绿系） |
|---|---|---|
| `--background` | 210 20% 98% | `150 33% 97%` 薄荷白 |
| `--foreground` | 215 28% 17% | `160 25% 15%` 深绿墨 |
| `--card` | 0 0% 100% | `0 0% 100%` 保留 |
| `--primary` | 168 72% 21% | `160 84% 32%` 明亮翠绿 |
| `--primary-glow` | 168 60% 35% | `158 70% 48%` 薄荷绿 |
| `--secondary` | 210 40% 96% | `150 40% 95%` 淡绿灰 |
| `--muted` | 210 25% 95% | `150 25% 95%` |
| `--muted-foreground` | 215 16% 45% | `160 12% 42%` |
| `--accent` | 168 65% 92% | `152 60% 92%` 淡薄荷 |
| `--accent-foreground` | 168 72% 21% | `160 84% 25%` |
| `--border` | 215 20% 90% | `150 25% 90%` 淡绿描边 |
| `--input` | 215 20% 90% | `150 25% 90%` |
| `--ring` | 168 72% 21% | `160 84% 39%` |
| `--success` | 142 65% 38% | `160 84% 35%`（与主色统一） |
| `--gradient-primary` | 深绿→中绿 | `linear-gradient(135deg, hsl(160 84% 35%), hsl(158 70% 50%))` 翠绿→薄荷 |
| `--gradient-glow` | 深绿光晕 | 薄荷绿光晕 |
| `--gradient-card` | 白→冷灰白 | `linear-gradient(180deg, #fff, hsl(150 30% 99%))` |
| `--shadow-card` / `--shadow-elevated` | 冷灰阴影 | 改为带绿调的极淡阴影 |
| body 背景径向光晕 | 深绿点缀 | 明翠绿点缀 |

**侧边栏令牌**改为浅色主题（对齐参考图左侧栏）：
- `--sidebar-background`: `150 33% 98%` 近白薄荷
- `--sidebar-foreground`: `160 20% 25%`
- `--sidebar-primary`: `160 84% 32%`
- `--sidebar-primary-foreground`: `0 0% 100%`
- `--sidebar-accent`: `152 55% 92%` 选中态浅绿块
- `--sidebar-accent-foreground`: `160 84% 25%`
- `--sidebar-border`: `150 25% 90%`
- `--sidebar-ring`: `160 84% 39%`

`warning / destructive / info` 保留现值（红/橙/蓝是状态语义色，参考图未展示相反视觉证据）。

`.glass-card` / `.neon-text-*` 全景看板组件的青/绿并存令牌保留（参考图未覆盖该场景），仅确保与新主色协调。

## 不改的内容

- 任何 `.tsx` 组件、页面结构、字段、文案、路由
- Tailwind 配置（颜色全部通过 CSS 变量映射，无需动 `tailwind.config.ts`）
- 组件的 className（已全部使用语义令牌）

## 验证

改完后目视检查：Dashboard、绿色制造模拟评价列表、评价指标表、侧边栏与参考图色调一致；跑一次 tsgo 确保无回归。
